# Spain day-by-day

Source for the family trip site published at `/spain/` on GitHub Pages.

```bash
npm install
npm run build
```

The build writes the static site to `../spain` with Vite `base: '/spain/'`. Serve the repository root and open `/spain/`.

Trip facts live in `src/data.ts` and come from the previous site. Do not add prices or places that are not already there.
